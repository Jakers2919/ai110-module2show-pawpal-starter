
# PawPal+ (Module 2 Project)

PawPal+ is a pet care scheduling app built with Python and Streamlit. It helps pet owners organize daily activities like feeding, walking, grooming, and playtime.

## Scenario

A busy pet owner needs help staying consistent with pet care. PawPal+ helps users:

- Track pet care tasks.
- Consider available time and task priorities.
- Generate a daily pet care schedule.
- Manage multiple pets.

## What You Will Build

The completed app will:

- Let users enter owner and pet information.
- Let users add tasks with duration and priority.
- Generate daily schedules based on available time and priorities.
- Display schedules clearly.
- Detect scheduling conflicts and support recurring tasks.
- Include automated tests.

## Getting Started

### Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Run the CLI Demo

```bash
python3 main.py
```

### Run the Streamlit App

```bash
streamlit run app.py
```

Note: The Streamlit interface is still a starter UI. Backend integration will be completed in Phase 3.
